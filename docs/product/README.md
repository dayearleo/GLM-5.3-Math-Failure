# Product

本仓库是一个公开数学题与模型 Session 个案审计，目标是把两个指定 GLM Session 未产出可见最终答复、而 Codex 首答识别原命题为假的情况提交给智谱 AI 关注。

范围：一个矩条件极差题、原始错误指数、后续更正指数、一个 Codex thread 和两个 ZCode Session；交付中文 README、标准题解和两份 Session 分析报告。

非目标：不宣称已经证明 GPT 或 GLM 的总体数学能力排序；不把本来为假的 (n^{-1/3}) 命题说成真定理；不把单次运行时长、Token 或输出状态推广为平均性能。当前 Feature 状态由根 `feature-list.md` 独占维护。
